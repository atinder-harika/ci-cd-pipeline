## 📖 What I'm Learning

This repository is my practical workshop for mastering CI/CD concepts. Each phase builds on the previous, culminating in production-ready pipelines for full-stack applications.

### Core Concepts Covered

- ✅ **Pipeline as Code (PaC)** - YAML-based workflow definitions
- ✅ **Automated Testing** - Unit, integration, and E2E test automation
- ✅ **Build Optimization** - Dependency caching and parallel jobs
- ✅ **Artifact Management** - Build output storage and versioning
- ✅ **Monorepo CI/CD** - Managing multiple projects in one repository
- ✅ **Matrix Builds** - Testing across multiple environments
